Установка и запуск.
установка зависимостей.
выполнение команды: make install (эта команда установит все пакеты).
запуск eslint: make lint (эта команда осуществляет проверку кода на отслеживание специфических ошибок)
запуск make lint-fix (эта команда по мере нахождения ошибок eslint может их исправлять. По крайней мере те ошибки, которые могут быть исправлены с гарантией сохранения работоспособности.)
